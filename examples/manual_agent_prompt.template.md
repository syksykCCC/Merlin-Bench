# Manual Start Instructions for an Evaluated Agent (Fallback)

> The `workspace/AGENT_PROMPT.md` generated by the preparation script is the primary and only
> recommended entry point.
>
> Use this template only when assembling a workspace manually.

## Time Budget

The default total wall-clock budget for each of the current 15 built-in tasks is **600 seconds
(10 minutes)**. The countdown begins when the host starts `arthur serve` and
loads the runtime; reading, programming, solving, checking, and submitting all count against the
budget. The countdown will normally already have begun when you see these instructions.

- Immediately run `python agent_client.py info` to confirm the public total budget, and record elapsed
  time yourself from now on.
- Set a finite timeout for every solver and subprocess; do not let one attempt consume the whole budget.
- For the 600-second budget, finish the main solve in about 500 seconds and reserve at least 100 seconds
  for checking, payload generation, and submission.
- `agent_client.py --timeout` is only the timeout for a single HTTP request; it cannot extend the global
  wall-clock budget.
- Arthur's terminal response must be received before the deadline. Merely starting the submission does
  not count as completion, and Arthur's verification also takes time.
- After the deadline, Arthur returns `TIMEOUT / BUDGET_EXCEEDED`.

You need to solve the specific instance in the current directory and submit the answer to the local
verifier, Arthur. This is a one-shot session and cannot be reset or retried.

1. Read `TASK_SPECIFICATION.md` in full; it is the authoritative description of the problem,
   mathematical notation, message fields, interaction order, and acceptance conditions.
2. Read `instance.json` and `protocol.json`; examples in the specification are not the answer to the
   current instance.
3. Run `python agent_client.py info` to confirm that Arthur is reachable and `next_sequence` is `0`.
4. Write the necessary solver, prover, and payload inside the current workspace, then actually submit
   through `python agent_client.py event ...`.
5. `sequence` starts at `0` and increases strictly. In a multi-round protocol, calculate the next
   message only using the challenge Arthur returned after the previous submission.
6. Continue until Arthur returns a terminal status. `ACCEPT` means the protocol passed; the final score
   is confirmed by the host's subsequent independent audit.

The current workspace contains every file you are allowed to use. Do not read, search, or modify any
path outside the workspace, and do not look for reference solvers, generator source code, or the
evaluator's `private/` or `official/` files.

Start solving now; do not provide only a plan.
